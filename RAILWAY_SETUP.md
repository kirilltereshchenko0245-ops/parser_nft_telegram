# 🚂 Настройка на Railway

## 📋 Переменные окружения (Environment Variables)

Перейдите в Railway → Settings → Variables и добавьте:

### Обязательные:

```
BOT_TOKEN = ваш_токен_от_BotFather
```

**Где взять:**
1. Откройте [@BotFather](https://t.me/BotFather)
2. Команда `/token` или `/newbot`
3. Скопируйте токен

---

```
OWNER_ID = ваш_telegram_id
```

**Где взять:**
1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ваш ID (число)

---

### Опциональные:

```
LOG_CHANNEL_ID = -1003864916255
```

**По умолчанию:** `-1003864916255` (уже настроено)

**Как изменить:**
1. Создайте свой приватный канал
2. Добавьте бота в админы канала
3. Узнайте ID канала через [@getmyid_bot](https://t.me/getmyid_bot)
4. Добавьте переменную на Railway

---

```
PROXY_URL = socks5://host:port
```

**Нужен только если Railway блокирует peek.tg API**

Обычно НЕ нужен!

---

## 🎯 Итого на Railway:

### Минимум (2 переменные):
```
BOT_TOKEN = 7xxxxxxxxx:AAHxxx...
OWNER_ID = 123456789
```

### Полный набор (3 переменные):
```
BOT_TOKEN = 7xxxxxxxxx:AAHxxx...
OWNER_ID = 123456789
LOG_CHANNEL_ID = -1003864916255
```

---

## 🚀 После добавления переменных:

1. Railway автоматически перезапустит бот
2. Проверьте логи: должно быть "Бот запускается..."
3. Напишите боту `/start`
4. Проверьте канал логов - должно появиться сообщение

---

## 🐛 Проблемы:

### Бот не отвечает:
```
Проверьте Variables → BOT_TOKEN
Должен быть формат: 1234567890:AAHxxxxxxxxxxxxxx
```

### Админка не работает:
```
Проверьте Variables → OWNER_ID
Должен быть ваш Telegram ID (число)
```

### Логи не приходят:
```
1. Бот должен быть админом канала LOG_CHANNEL_ID
2. Проверьте формат: -1001234567890 (начинается с минуса)
```
