## Чтобы обновить бот:

### Способ 1: Через Git (рекомендуется)

```powershell
# В папке проекта выполни:
git add .
git commit -m "Add detailed logging"
git push
```

Render автоматически задеплоит через 2-3 минуты.

### Способ 2: Через Render Dashboard

1. Зайди на dashboard.render.com
2. Открой свой Web Service
3. Нажми **Manual Deploy** → **Deploy latest commit**

## После деплоя:

1. Зайди в **Logs** на Render
2. Запусти парсинг в боте
3. В логах увидишь детальную информацию:
   ```
   INFO:root:Gift 1: HTTP 200
   INFO:root:Gift 1: not found (no owner)
   INFO:root:Gift 2: HTTP 200
   INFO:root:Gift 2: FOUND!
   ```

Это поможет понять, почему не находятся подарки!

## Возможные причины "не находит":

1. **В диапазоне нет владельцев** - это нормально, просто подарки пока не отданы
2. **403 ошибки** - API блокирует, но бот автоматически повторяет
3. **Неправильное название модели** - проверь точное название
