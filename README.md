# GiftParser 5.2 — Telegram-only

Telegram-бот для поиска NFT-подарков через Peek.tg. Весь интерфейс работает внутри Telegram: сайт и Mini App не нужны.

## Возможности

- Поиск по модели и диапазону ID (до 10 000 ID за запуск).
- Проверка одного ID и случайная проверка ID.
- Каталог моделей с пагинацией и подсказки при опечатках.
- Карточки находок, Telegram-ссылки на подарок и владельца.
- История поисков, продолжение остановленных/ошибочных поисков.
- Избранное, пагинация и экспорт результатов в TXT.
- Trial, Premium и админ-команды `/grant`, `/revoke`, `/ban`, `/unban`.
- Повторные запросы к Peek, пауза между запросами и обработка flood-лимитов Telegram.
- Админ-панель со статистикой, пользователями, последними поисками и просмотром логов.
- Поиск моделей прямо из каталога.
- Случайный подарок с выбором модели.
- Кнопки «Стоп» и «Продолжить», последний незавершённый поиск доступен из «Новый поиск».
- Автоматические миграции существующей SQLite-базы.

## Локальный запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `BOT_TOKEN` и `OWNER_ID` в `.env`, затем:

```bash
python bot.py
```

Если у вас уже есть `bot_database.db`, положите его рядом с `bot.py` и задайте `DATABASE_PATH=bot_database.db`. Миграции добавят недостающие поля без удаления старых данных.

## Деплой на Railway

1. Создайте новый Railway project из GitHub-репозитория с этими файлами.
2. Добавьте Railway Volume и подключите его к сервису по пути `/data`.
3. В Variables задайте `BOT_TOKEN`, `OWNER_ID`, `DATABASE_PATH=/data/bot_database.db` и при необходимости `PEEK_CONCURRENCY` / `PROXY_URL`.
4. Убедитесь, что команда запуска — `python bot.py` (она также указана в `railway.toml` и `Procfile`).
5. Не запускайте более одного worker с одной базой SQLite. Для нескольких реплик понадобится внешняя БД и распределённая блокировка.

**Важно:** без постоянного Volume SQLite-файл в Railway может быть потерян при пересоздании контейнера. Для переноса старой базы загрузите `bot_database.db` в подключённый Volume до первого запуска.

## Админ-команды

Команды принимают числовой Telegram ID уже зарегистрированного пользователя:

- `/grant 123456789` — выдать Premium.
- `/revoke 123456789` — снять Premium.
- `/ban 123456789` — заблокировать.
- `/unban 123456789` — разблокировать.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота | обязательна |
| `OWNER_ID` | Telegram ID владельца | `0` |
| `PEEK_CONCURRENCY` | Параллельные запросы к Peek | `5` |
| `DATABASE_PATH` | Путь к SQLite-файлу | `bot_database.db` |
| `PROXY_URL` | Необязательный HTTP/SOCKS proxy | выключен |

## Ограничения

- Список моделей берётся из `peek_api.py`; доступность моделей и формат ответа Peek зависят от внешнего API.
- Остановка активного поиска действует в памяти процесса и не переживает перезапуск бота.
- Для надёжного хранения данных на Railway обязателен Volume.
- Premium в этой версии назначается владельцем вручную; встроенной оплаты нет.
