# 🎁 Telegram Gift Parser Bot

Продвинутый бот для парсинга NFT-подарков Telegram через Peek API.

## ✨ Возможности

### 🎨 Интерфейс
- ✅ Удобные кнопки вместо команд
- ✅ Красивое оформление результатов
- ✅ Inline кнопки для быстрого перехода к владельцу
- ✅ Прогресс-бар в реальном времени

### 📊 Функционал
- ✅ Поиск подарков по модели и диапазону ID
- ✅ Ввод диапазона через тире (например: 10-20, 13000-13100)
- ✅ Продолжение незавершённого поиска
- ✅ История всех поисков с пагинацией
- ✅ Профиль пользователя со статистикой
- ✅ Сохранение найденных подарков в БД

### 🎫 Система лимитов
- ✅ Пробный период: 50 поисков по 50 ID
- ✅ Premium: безлимитный доступ
- ✅ Автоматическое отслеживание использования

### ⚙️ Админ-панель
- ✅ Общая статистика бота
- ✅ Бан/разбан пользователей
- ✅ Выдача Premium статуса
- ✅ Режимы доступа: только владелец / все пользователи
- ✅ Просмотр информации о пользователях

### 🔒 Безопасность
- ✅ Защита от спама (3 сек между запросами)
- ✅ Retry логика при ошибках (не пропускает ID)
- ✅ Система банов
- ✅ Контроль доступа

## 🚀 Быстрый старт

### 1. Создай бота

1. Напиши [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Следуй инструкциям
4. Скопируй токен

### 2. Узнай свой Telegram ID

Напиши [@userinfobot](https://t.me/userinfobot) и скопируй свой ID.

### 3. Настрой переменные окружения на Render

В Render Dashboard → Environment добавь:

```
BOT_TOKEN=твой_токен_от_BotFather
OWNER_ID=твой_telegram_id
```

⚠️ **НЕ добавляй** `PROXY_URL` на Render!

### 4. Деплой

Render автоматически задеплоит бота из GitHub.

## 📱 Команды бота

После `/start` доступны кнопки:

- 🔍 **Начать поиск** - новый парсинг подарков
- 📊 **Профиль** - твоя статистика и информация
- 📜 **История** - все твои поиски с результатами
- ⏭️ **Продолжить** - продолжить последний незавершённый поиск
- ℹ️ **Помощь** - инструкция по использованию
- ⚙️ **Админка** - панель администратора (только для владельца)

## 🎯 Как пользоваться

1. Нажми **🔍 Начать поиск**
2. Введи название модели (например: `EternalRose`)
3. Введи диапазон через тире (например: `13000-13100`)
4. Жди результаты!

Бот будет:
- Проверять каждый ID в диапазоне
- Показывать прогресс в реальном времени
- Отправлять красиво оформленные карточки найденных подарков
- Сохранять всё в историю

## 💎 Информация о подарке

Для каждого найденного подарка показывается:
- 🆔 ID подарка
- 🎨 Название и модель
- ✨ Узор с процентом редкости
- 🌈 Фон с процентом редкости
- 👤 Владелец (username или ID)
- 💰 Цена на маркетплейсе (если есть)
- 🔗 Прямая ссылка на подарок
- 👤 Кнопка перехода к владельцу

## 🏗️ Технологии

- **Python 3.8+**
- **aiogram 3.x** - фреймворк для Telegram ботов
- **aiohttp** - асинхронные HTTP запросы

- **Peek API** - источник данных о подарках

## 🔧 Локальная разработка

Для запуска локально (Windows):

1. Установи зависимости:
```powershell
pip install -r requirements.txt
```

2. Создай `.env`:
```
BOT_TOKEN=твой_токен
OWNER_ID=твой_id
PROXY_URL=socks5://192.168.0.100:10808
```

3. Запусти:
```powershell
python bot.py
```

⚠️ В России нужен SOCKS5 прокси для работы с Telegram API!

## 💡 Советы

### Оптимальные диапазоны
- Пробным: до 50 ID (например: 1-50)
- Premium: до 5000 ID (например: 10000-15000)

### Время парсинга
- ~3 секунды на 1 ID
- 50 ID = ~2.5 минуты
- 100 ID = ~5 минут

- EternalRose
- BlueStar
- Delicious
- GoldenGift

## 🐛 Проблемы?

### Бот не отвечает
- Проверь, что бот запущен на Render
- Убедись, что токен правильный
- Проверь логи на Render

### Conflict ошибка
- Останови другие экземпляры бота
- Может быть запущен локально и на Render одновременно

### 403 ошибки в логах
- Это нормально! Бот автоматически делает retry
- Peek API иногда блокирует при большом количестве запросов
- Задержка 3 сек помогает избежать блокировок
