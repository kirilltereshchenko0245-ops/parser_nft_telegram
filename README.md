# GiftParser 5.1

Telegram-бот для поиска NFT-подарков через Peek.tg.

## Запуск
1. Python 3.11+
2. `pip install -r requirements.txt`
3. Скопировать `.env.example` в `.env`, заполнить `BOT_TOKEN` и `OWNER_ID`
4. `python bot.py`

Старый `bot_database.db` подхватывается автоматически: недостающие таблицы и колонки добавляются сами.

## Что нового в 5.1
**Дизайн**
- единый стиль всех экранов (`ui.py`): цитатные блоки, прогресс-бар ▰▱, ꜱᴍᴀʟʟ ᴄᴀᴘꜱ-заголовки
- карточки подарков с превью `t.me/nft/…`: виден сам подарок
- история, результаты, избранное и каталог моделей — компактные списки с кнопками и пагинацией
- «Остановить» — инлайн-кнопка под статусом, меню не пропадает

**Функции**
- экспорт результатов в TXT (был в README, но не был реализован)
- каталог моделей: нажал на модель — сразу вводишь диапазон
- подсказки при опечатке в названии модели
- команды админа: `/grant`, `/revoke`, `/ban`, `/unban`, список пользователей

**Исправления**
- «Продолжить» из истории брало ID бота вместо ID пользователя
- ошибки 403/429 после всех ретраев считались «подарок не найден» — теперь это ошибка, ID повторяется
- ссылки в истории и избранном вели на неверный адрес (использовалась модель вместо коллекции)
- Trial списывается по ходу поиска, а не только при полном завершении
- защита от двойного запуска поиска и от flood-лимитов Telegram
- миграция БД теперь добавляет все недостающие колонки старых версий
