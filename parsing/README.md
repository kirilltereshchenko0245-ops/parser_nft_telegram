# V42 — Offer route diagnostics

Исправленная диагностическая сборка.

Команды в Business-чате:
- `.тестофер` — минимальное сообщение без inline-кнопки.
- `.тестофер2` — минимальное сообщение с одной inline-кнопкой.
- `.офер` — штатный DEMO-офер.

Обе тестовые команды зарегистрированы непосредственно в том же Dispatcher,
что и Business-обработчики, и используют тот же business_connection_id.

Если тест не может отправиться, обработчик пытается показать ошибку прямо в том же Business-чате.
