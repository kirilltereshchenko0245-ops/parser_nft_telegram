# 🚀 Инструкция по деплою обновлённого бота

## Шаг 1: Установка Git (если не установлен)

Скачай и установи Git: https://git-scm.com/download/win

## Шаг 2: Запуш кода на GitHub

Открой PowerShell в папке проекта и выполни:

```powershell
# Инициализация Git (если ещё не сделано)
git init

# Добавить все файлы
git add .

# Создать коммит
git commit -m "Major update: UI with buttons, database, profiles, admin panel"

# Если репозиторий ещё не создан на GitHub:
# 1. Создай новый репозиторий на https://github.com/new
# 2. НЕ добавляй README, .gitignore или лицензию
# 3. Скопируй URL репозитория

# Добавить remote (замени URL на свой)
git remote add origin https://github.com/твой-username/твой-репозиторий.git

# Или если remote уже есть, обнови его
git remote set-url origin https://github.com/твой-username/твой-репозиторий.git

# Установить ветку main
git branch -M main

# Запушить
git push -u origin main
```

## Шаг 3: Настройка Render

1. Зайди в Render Dashboard
2. Открой свой Web Service
3. Перейди в **Environment**
4. Обнови/добавь переменные:
   ```
   BOT_TOKEN=новый_токен_от_BotFather
   OWNER_ID=твой_telegram_id
   ```
5. **УДАЛИ** `PROXY_URL` если он там есть (на Render не нужен)
6. Сохрани изменения

## Шаг 4: Manual Deploy

1. В Render перейди в **Manual Deploy**
2. Нажми **Deploy latest commit**
3. Подожди ~2-3 минуты
4. Проверь логи - должно быть "Бот запущен!"

## Шаг 5: Тест

Напиши `/start` своему новому боту.

Должно появиться:
- Приветствие
- Кнопки: 🔍 Начать поиск, 📊 Профиль, и т.д.

## 🐛 Если не работает

1. **Conflict ошибка** - останови старый бот (если запущен локально)
2. **Старый интерфейс** - убедись что код запушен на GitHub и Render сделал redeploy
3. **403 ошибки** - это нормально, бот автоматически retry делает

## ✅ Что должно работать

- ✅ Кнопки вместо команд
- ✅ Профиль с статистикой
- ✅ История поисков
- ✅ Диапазон через тире (10-20)
